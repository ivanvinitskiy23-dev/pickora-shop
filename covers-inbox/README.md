# Covers inbox (on git)

Сюда Cover-агент кладёт готовые обложки статей.

| Правило | Значение |
|---|---|
| Формат | WebP предпочтительно; PNG/JPG ок до конвертации |
| Размер | ~1200×670 (16:9), цель **≤ 250 KB** |
| Имя | `{slug}-cover.webp` |
| Загрузка | ты сам через Pickora Studio → Медиа / обложка статьи |
