# Pickora Pinterest playbook

## Why Pinterest for Pickora

- Visual niches (kitchen gadgets, earbuds, cleaning, pets) pin well.
- Pins have long shelf life → evergreen guides from `CONTENT-BANK.md`.
- Goal: **pin → article → Amazon CTA**, not pin → Amazon (disclosure + cookie path via site).

## Account setup (user does once)

- [ ] Pinterest Business profile
- [ ] Claim website `pickora.shop` (meta tag or HTML file — only with user’s real verification)
- [ ] Rich Pins / URL metadata working (OG title + image on articles)
- [ ] Boards named by intent, not brand fluff (see map below)

Do **not** invent the user’s profile URL. Ask for it.

## Pin formats that convert for affiliate guides

| Format | Idea | Image brief |
|---|---|---|
| List / ranking | “Best air fryers 2026 — which size to skip” | Vertical 1000×1500, big title, 3 product silhouettes or size labels |
| Mistakes | “5 air fryer buying mistakes” | Numbered checklist on lifestyle kitchen photo |
| Vs | “Ninja vs Cosori — pick in 30 seconds” | Split layout, clear winner question |
| How-to | “How to choose a microwave 2026” | Simple decision tree graphic |
| Single CTA | “Best for small kitchens” | One hero product + room context |

**Aspect:** 2:3 (e.g. 1000×1500). Brand colors: navy `#15223B`, blue `#2075D2`, light bg — not purple glow spam.

## Pin copy template

```
Title (≤100 chars, front-load keyword):
{Primary benefit or year} — {niche} | Pickora

Description (≤500 chars):
{Hook}. {Who it’s for / who should skip}. Full guide: {https://pickora.shop/{slug}/}
{2–4 hashtags max, niche-specific}
```

Rules:
- Destination = **article URL**, not Amazon.
- No fake “tested for 100 hours” unless the live article already says research-only voice.
- Hashtags: 2–4 relevant (`#airfryer` `#kitchengadgets`), not 20 junk tags.
- Affiliate disclosure can live on site; pin can say “buying guide” / “affiliate links in article” if needed for clarity.

## Weekly cadence (realistic solo)

| Day | Action |
|---|---|
| Mon | 2–3 pins for one live P1 article (different creatives) |
| Wed | 2 pins for a second niche |
| Fri | Repin/refresh weakest board; check top outbound article |
| Anytime | After each new `live` article → pin pack same day |

Consistency > volume. 5–10 quality pins/week beats 50 spam.

## Idea sources

1. Live slugs already on site
2. `CONTENT-BANK.md` P1 ideas → plan pins **after** publish
3. Pinterest search autocomplete for “best … 2026”, “buying mistakes”, “vs”
4. User-pasted Pin analytics (impressions, outbound clicks)

## Image generation brief (for Cursor / designer)

When asking for a pin image, specify:
- Size 1000×1500
- Headline text (exact)
- Subline (optional)
- Niche visual (kitchen / earbuds / vacuum / pet)
- Pickora wordmark small, not overpowering
- No fake Amazon UI, no scraped product CDN photos as permanent assets

## Anti-patterns

- Linking pin straight to `amzn.to` (skips site SEO + trust)
- Duplicate title+image spam across boards same day
- Empty boards with only 1 pin
- Inventing Pinterest profile/board URLs
- Claiming “guaranteed viral”
