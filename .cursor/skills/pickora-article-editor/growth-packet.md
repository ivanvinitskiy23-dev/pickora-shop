# Growth packet (after draft)

Emit once a draft exists (before or with editor approve). Destination is always the **article URL**, never `amzn.to`.

## Packet format

```markdown
## Growth packet — {slug}

**Destination URL:** https://pickora.shop/{slug}/

### Keywords
- Primary: …
- Secondary: …
- Pinterest / discovery: …

### Title / meta (proposed)
- Title (≤~60): …
- Meta description (≤~155): …
- H1: …

### 3 pin angles (guide pins → article)
1. **Angle:** … | Hook: … | Visual: …
2. **Angle:** … | Hook: … | Visual: …
3. **Angle:** … | Hook: … | Visual: …
```

Save optional copy to `briefs/drafts/{slug}-growth.md`. Hand to Growth agent when user asks for pins/boards — do not invent Pinterest profile URLs.
