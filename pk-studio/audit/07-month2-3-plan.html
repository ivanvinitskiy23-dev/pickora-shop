Риски / границы:
  • C5 N reviews: сейчас hard = 4 в API + live grid. Делаем 3–6 слотов (не бесконечно): обновить Studio + publish_home + preview; live CSS grid уже flex — проверить визуально.

  • Archive article: status archived, noindex meta, убрать карточку с articles hub при следующем publish; не удалять файлы с GitHub в MVP (soft archive).
  • Не трогаем Telegram CMS / unpaid social. Не scrape Amazon.

Месяц 3 — пакеты

M3-P1 D2 Rollback UX

  • Поле имени снимка при publish (detail/label)
  • В списке snapshots: показать urls/files count из payload если есть
  • Confirm: «Откатит module X, snapshot name, дата»
  • После rollback — toast + reload module list

Файлы: ops.js, index.js recordSnapshot, i18n

Acceptance: rollback confirm показывает module+time; успех обновляет audit

M3-P2 D3 Links queue

  • Клиент: батчи по 20, очередь, прогресс «batch 2/5»
  • Сервер: оставить cap 20 на request (SSRF safety)
  • После Save Home/Pins/Products — optional soft rescan status (не блокировать)

Acceptance: 45 ссылок → 3 батча; итог показывает all checked count

M3-P3 E1 Team roles

  • Invite role select: admin | editor | viewer
  • API: requireWrite(user) — viewer 403 на POST content/publish/media delete
  • Studio: session.role → hide Save/Publish/Team invite for viewer; show badge
  • Activity: audit list already exists — показать на Status «кто сохранил»

Acceptance: viewer login → Save disabled; POST content → 403

M3-P4 F UX polish

  • Toast helper (2с success) поверх pill
  • Disable Save когда !dirty (Home/Pins/Products fingerprints + Articles)
  • beforeunload + nav click confirm если dirty
  • Sticky save bar для Home/Pins (как Products)
  • Ctrl/Cmd+S → save активного модуля; Esc → close art-settings
  • Dash counters: N drafts, N media (из API)

Acceptance: без правок Save disabled; dirty leave → confirm; Ctrl+S сохраняет

Definition of Done + Re-audit

  1. node --check на всех изменённых JS
  2. Ручной чеклист: login → каждая вкладка открывается без console error
  3. Articles: search, duplicate, archive, chips, meters, autosave restore, template, Ctrl+S
  4. Products: bulk paste, hide, import JSON; Pins: featured; Home: 5 reviews + drag picks
  5. Publish dry-run still works; rollback confirm shows label
  6. Viewer session: cannot save (если тестовый user есть — иначе code-review guards)
  7. SEO links: 25+ URLs batch progress
  8. Bug hunt pass → fix all found → commit/push → wrangler deploy → health OK
