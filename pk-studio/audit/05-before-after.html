Критичные и P1

A-01 · Team owner

Было

Invite-панель не видела owner: sessionIsOwner ждал s.user.owner, а сессия плоская.

Стало

Читает s.owner / s.user.owner / role — invite и remove работают у владельца.

A-02 · Offline preview Home/Pins

Было

Офлайн-превью только у Products/Articles. Home и Pins — только Live.

Стало

POST /api/preview/home|pins + кнопки «Проверить офлайн» в Studio.

A-03 · Buy URL на Save

Было

Можно сохранить пустые amzn.to/ / link.amazon/.

Стало

isGoodBuyUrl на saveHome / savePins / products.

A-04 · Publish preflight

Было

Publish модуля сразу бил в GitHub без чеклиста.

Стало

Confirm с счётчиками (picks/reviews/hubs) перед publish.

A-05 · Media delete refs

Было

Delete файла без предупреждения, что он в черновиках.

Стало

Скан home/pins/products/articles → confirm со списком usages.

A-06 · Media upload UI

Было

В Media только список и delete.

Стало

Upload + показ path + Copy path.

Контент-редакторы

A-07 / A-08 · Multi-store Pins + Top picks

Было

Пины — textarea; top picks — один Amazon URL.

Стало

Один редактор buyLinksEditorHtml; карусель рендерит несколько CTA из links[].

A-09 · Import live article

Было

Live-список статей только для просмотра.

Стало

«Импорт в черновик» через GET /api/articles/:slug/live (нужен JSON на GitHub).

A-18 / A-36 · Pins UX

Было

Нет reorder; shuffle всегда; filters не редактируются.

Стало

↑↓, чекбокс shuffleOnLoad, редактор фильтров категорий.

A-33 / A-37 / A-42 · Не терять правки

Было

Смена языка сбрасывала top picks; reopen Articles — черновик; дубли URL reviews проходили.

Стало

readTopPicksForm перед re-render; confirm dirty; блок дублей URL.

A-40 · Live articles list

Было

Только первые 20 live-статей.

Стало

Все + поиск.

API / безопасность / publish

A-21 · SSRF links/check

Было

Worker fetch’ил любые URL от авторизованного админа.

Стало

Allowlist Amazon/Walmart/BestBuy/Target/Pickora + блок private IP.

A-24…A-31 · Team / auth / media API

Было

Audit log писал target; OWNER trim рассинхрон; delete 200 на missing; ON CONFLICT overwrite; orphan на GitHub; 401 без logout; verifyPassword падал на null salt.

Стало

Actor в audit; общий ownerEnvCredentials; 404; insert-only+retry; deleteFile на GH; apiFetch 401→reload; null-guard на hash.

A-35 / A-39 · Publish HTML patch

Было

Пустые top picks оставляли stale shell; карточка продукта без buy-кнопок ломала replace.

Стало

Всегда patch shell (в т.ч. clear); depth-walk конца карточки без кнопок.

A-41 / A-43 · HTML blocks + hubs

Было

Блок html без sanitize; hub без страницы молча skip только на publish.

Стало

sanitizeRichHtml на compile; /api/probe/hubs + confirm на Save.
