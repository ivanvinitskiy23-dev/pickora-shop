Pickora Studio · Документ 4/4

План развития админ-панели (до мелочей)

Не баги, а рост: чтобы сайт, статьи, товары, пины и картинки чинились и публиковались молниеносно — без ручного Git, без «где этот файл».

1. План аудита 2. Полный аудит + решения 3. План исправлений 4. План развития 5. Было → стало

North star

Владелец за 60 секунд может: заменить обложку, поправить Amazon/Walmart, проверить офлайн-превью и нажать Publish — без Cursor и без SSH.

A. Молниеносные картинки

A1. Media Library 2.0

  • Upload drag-drop + multi-file
  • Поиск по имени / alt / дате
  • «Используется в…» (home/pins/products/article)
  • Копировать: Worker URL / /wp-content/… / Markdown
  • Replace-in-place: новая версия файла, тот же SEO-path (опционально confirm overwrite)

A2. Быстрая замена на карточке

  • Кнопка «Заменить» рядом с thumb (не только Upload)
  • Превью до Save (object URL)
  • «Взять из Media» picker modal
  • Авто-alt из title товара/пина (editable)

A3. Cover pipeline статей

  • Проверка ≤250KB / 16:9 прямо в Studio
  • Генерация slug-cover имени
  • Показ OG-preview (как в Facebook/Telegram)

A4. Мелочи картинок

  • Индикатор «Pages ещё не подхватил» vs Worker OK
  • Кнопка «Открыть оригинал»
  • Запрет hotlink Amazon CDN с красным флагом
  • Массовый «пересжать WebP»

B. Статьи — скорость правок

B1. Open anything

  • Импорт live статьи → draft
  • Поиск по slug/title в Studio
  • Duplicate article
  • Archive / unpublish (noindex + hub remove)

B2. Блоки

  • Duplicate block (код уже почти есть)
  • Templates библиотека (microwave / vs / mistakes)
  • Вставка affiliate из Media+Products picker
  • Autosave каждые N сек + «восстановить»

B3. SEO cockpit

  • Live preview title/description length meter
  • Internal link suggester (существующие slugs)
  • Chips UI (checkbox 1–3) вместо сырого текста
  • Sitemap include/exclude toggle

B4. Мелочи статей

  • Keyboard: Ctrl+S save, Esc close settings
  • Dirty-state «есть несохранённое»
  • Сравнение draft vs live (diff)
  • Чеклист before seo_ready компактной полосой

C. Products / Pins / Home — один язык

C1. Единый Buy Links

  • Один компонент на Products, Pins, Home, Article blocks
  • Пресеты: Amazon / Walmart / Best Buy / Other
  • Проверка HEAD из Studio (reuse links/check)

C2. Offline везде

  • Home offline (уже в fix-plan)
  • Pins offline
  • Articles hub card preview
  • «Сравнить с Live» split view

C3. Products power

  • Bulk paste 5 товаров из SEO-агента (JSON/CSV)
  • Duplicate product across hubs
  • Hide product without delete
  • Sort: manual / rating / title

C4. Pins power

  • Structured pin products UI
  • Reorder + pin «featured»
  • Отключить random shuffle на live (настройка)
  • Фильтры редактировать в UI (сейчас в JSON)

C5. Home power

  • Не только 4 reviews — N слотов
  • Drag-and-drop order Top picks
  • Schedule «показать с даты»
  • Quick-swap cover from Articles catalog

C6. Мелочи каталога

  • Счётчик «черновик ≠ live» badge на вкладке
  • Confirm перед Delete section
  • Undo последнего delete (session)
  • Empty-state с CTA «добавить первый товар»

D. Publish / качество live

D1. Safe Publish

  • Preflight для всех модулей
  • Dry-run: показать diff file list
  • «Publish selected hub only»
  • Прогресс: uploading… commit… Pages

D2. Rollback UX

  • Превью что откатится
  • Имя снимка («before pets refresh»)
  • Сравнение snapshot vs now

D3. Links & SEO ops

  • Check >20 links (очередь)
  • Авто-рескан после Save
  • Отчёт «битые на live HTML» (crawl sitemap)
  • Amazon short-link health digest в Status

D4. Мелочи ship

  • Кнопка «Открыть commit на GitHub»
  • Показывать Pages build delay tip
  • One-click «purge CF cache» если появится

E. Команда, доступ, доверие

E1. Team

  • Роли: owner / editor / viewer
  • Viewer = только preview
  • Activity: кто что сохранил

E2. Safety

  • 2FA позже (если нужно)
  • Session expiry banner
  • Не показывать owner login в HTML

E3. Мелочи доверия

  • «Вы вошли как … · Owner»
  • Last save time на каждой панели
  • Environment badge: Live API vs Local :8787

F. UX-полировка (мелочи, которые бесят каждый день)

  • Sticky actions уже у Products — такой же паттерн для Home/Pins/Articles Save
  • Toast вместо только pill-status (успех 2 сек)
  • Disable Save button пока нет dirty
  • Confirm leave page if dirty
  • Мобильный sidebar: закрывать после выбора раздела (частично есть)
  • Фокус-ловушка в art-settings drawer
  • Скелетоны загрузки списков
  • Единые empty states с иллюстрацией-текстом
  • Все hardcoded EN labels («Pros», «Badge») → i18n
  • Dash: реальные счётчики (N drafts, N broken links) вместо статики
  • Клавиатура: ? — шпаргалка хоткеев
  • Тёмная тема — не приоритет (сайт светлый; Studio может остаться светлой)
