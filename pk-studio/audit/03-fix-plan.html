Правила выполнения

  • Один PR/коммит = одна фаза или одна P0/P1 тема (не мешать с roadmap-фичами).
  • После Studio UI — bump ?v= на всех затронутых assets.
  • После admin-api — wrangler deploy.
  • Не публиковать на live без вашей явной команды Publish.
